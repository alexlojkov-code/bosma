Что вы вводите

Описание бизнеса, идею поста, выбранную соцсеть, язык и тон. Не вводите в эти поля пароли, номера карт и другие данные, которые не должны попасть в пост.

Куда уходит текст

Чтобы написать пост, сервер Bosma передаёт введённый текст в Google Gemini API и сразу возвращает вам ответ модели. Сервер не сохраняет описания, идеи и посты. В журнал запросов попадают только технические данные: время, соцсеть, язык, длительность, число токенов и код ошибки.

Пока сервис работает на бесплатном тарифе Gemini API, Google может использовать переданные тексты для улучшения своих продуктов — по правилам Google. Подробнее — в условиях Gemini API на сайте Google.

Архив постов

Готовые посты и ваши настройки хранятся только в этом браузере, в его локальном хранилище. Мы их не видим. Удалить их можно кнопкой «Очистить архив» или очисткой данных сайта в браузере.

Ограничение запросов

Чтобы защитить сервис от злоупотреблений, сервер на время учитывает число запросов с одного IP-адреса. Адрес хранится только в оперативной памяти сервера и не записывается в журнал.

Контакт

Вопросы по данным — через владельца сервиса. Контакт будет указан здесь перед публичным запуском.
